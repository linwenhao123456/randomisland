随机空岛 Random Island

轻量随机空岛生存。出生在虚空中的小岛，每 60 秒岛上的方块会随机重组，并刷新随机奖励箱；仅主世界为空岛，下界与末地保持原版。

核心特性

🏝️

随机空岛

出生在虚空中的小岛；每 60 秒岛上的 3×3×3 方块会整体随机重组——这就是“随机空岛”。

🎁

随机奖励箱

每 60 秒在玩家附近刷新一个随机奖励箱，让空岛不再枯燥。

⚙️

可配置

通过 ModMenu / 配置文件调整空岛大小、奖励箱间隔等参数。

🌍

仅主世界

空岛只作用于主世界；下界与末地保持原版，探索不打折。

安装步骤

  1. 安装前置：先安装 Fabric Loader 与 Fabric API（建议搭配 ModMenu 查看配置）。
  2. 下载 Mod：点击上方「下载 Mod」，得到 random_island-1.0.0.jar。
  3. 放入 mods：把 jar 放进你的游戏实例 mods/ 文件夹。
  4. 创建世界：单人游戏 → 创建世界 → 「更多世界的选项」→ 世界类型选 「随机空岛（虚空）」 → 创建。

指令教学

所有指令均可由任意权限玩家使用（默认 0 级）。进入空岛世界后，在聊天框输入即可。下面列出全部指令与示例。

/randomisland

查看当前状态报告（维度 / 是否空岛世界 / 空岛是否已生成 / 日志路径）。

/randomisland build

强制重建空岛与起步箱（忽略“已生成”标记），适合把已有世界改造成空岛。

/randomisland transform

立即把原点 3×3×3 的方块随机重组一次（按当前方块池）。

/randomisland interval <秒>

设置空岛方块变换间隔，例如 /randomisland interval 30 改为每 30 秒一变。

/randomisland refresh [force]

立即刷新一个随机奖励箱；加 force 忽略概率必出。

/randomisland skyblock

把你自己传送到空岛出生点（迷路时很有用）。

/randomisland allblocks [on|off]

全方块模式：on 时随机池使用全部已注册方块（含其它 mod），off 时用默认/自定义权重表。

/randomisland allitems [on|off]

全物品模式：on 时随机箱掉落全部已注册物品（含其它 mod），off 时用默认/自定义掉落池。

/randomisland uniform [on|off]

全方块统一：on 时岛上每个位置都不同（全都不一样）；off 时整座岛都是同一种随机方块。

/randomisland weight

查看当前方块权重表。配合 set <方块> <权重> / remove <方块> / reset 增删与还原。

/randomisland reset

一键恢复全部默认设置（含空岛权重、掉落池、各开关）。

/randomisland help

在游戏内打开这条指令与玩法帮助。

常见问题 QA

Q: 如何在单人游戏中创建随机空岛？

A: 单人游戏 → 创建世界 → 「更多世界的选项」→ 世界类型选 「随机空岛（虚空）」 → 创建。

Q: 为什么在「世界类型」里找不到「随机空岛（虚空）」？

A: 先在 ModMenu / 模组列表确认“随机空岛”已加载；预设要在创建世界的「更多世界的选项」里反复点「世界类型」循环切换才会出现在列表。若仍没有，查看游戏日志是否有注册报错。

Q: 空岛方块为什么会一直变 / 每 60 秒重组？

A: 这是本 mod 的核心玩法——原点 3×3×3 的方块每 60 秒按权重随机重组一次，无论原来有没有方块。如需稳定空岛，可在 ModMenu 关闭 randomizeIsland。

Q: 怎么调整变换间隔，或让空岛立即变换？

A: 指令 /randomisland interval <秒> 设置间隔；/randomisland transform 立即变换一次。两项也可在 ModMenu 中修改。

Q: 怎么自定义随机方块的种类与概率（权重）？

A: 用 /randomisland weight set <方块> <权重> 设置，/randomisland weight 查看，/randomisland weight reset 恢复默认；也可直接编辑配置 config/random_island.json 的 islandPalette。

Q: 没有装 ModMenu 也能配置吗？

A: 可以。配置写在游戏目录 config/random_island.json，手动编辑后重启游戏即生效。

Q: 随机奖励箱不刷新 / 很少出现？

A: 刷新受 chestSpawnChance 概率与 refreshInterval 间隔控制；用 /randomisland refresh force 强制刷一次排查。请确认你处于空岛（void）主世界。

Q: 下界和末地也是空岛吗？

A: 不是。空岛只作用于主世界；下界与末地保持原版地形。

Q: 支持哪些 Minecraft 版本与加载器？

A: 当前为 Minecraft 1.20.1 + Fabric Loader（需 Fabric API）。页面顶部显示当前支持版本。

Q: 怎么一键恢复所有默认设置？

A: /randomisland reset 恢复全部默认（含空岛权重与奖励池）；方块权重单独用 /randomisland weight reset。

Q: 配置文件与运行日志在哪？

A: 配置：.minecraft/config/random_island.json；运行日志：.minecraft/config/random_island/mod_running_log.txt。
